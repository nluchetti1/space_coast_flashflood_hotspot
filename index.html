Hot spots active at this threshold

    How to read this. Each hot spot is a cluster of NWS flood / flash-flood reports. For each report, the build finds the peak Stage IV accumulation for each duration (1–72 h) over windows ending between 12 h before the report and 2 h after it. A spot's trigger for a duration is the lowest peak that has produced a flood report there. The spot lights up when the threshold is at or above its trigger.

    Caveats. Reports only exist where flooding was seen and reported, so the secured interiors of CCSFS and KSC are under-sampled. Stage IV is about 4.7 km. Values marked † fell back to 6-hourly files because of gaps in the hourly data. There's no record of heavy rain that didn't flood a spot, so each trigger is an upper bound on the true threshold. Tropical events can mix lagoon or surge water with rainfall flooding.

    Data: IEM LSR archive, NCEI Storm Events, NCEP Stage IV via IEM.

    Closest to flooding

      How this works. For each hot spot, the page samples the latest MRMS 1, 3, 6, 12, 24, 48 and 72 h totals at the spot and divides each by that spot's historical trigger for the same duration. The highest ratio sets the status: 100% means rain has already reached an amount that has flooded this spot before. Click anywhere for the current totals at that point.

      Caveats. Triggers come from Stage IV, and MRMS radar-only can run high or low against it, especially in tropical rain and on the edges of the radar's coverage. Multi-sensor Pass 2 is closer to Stage IV but lags about an hour. MRMS refreshes about every 10 min via GitHub Actions, which can be delayed; check the valid times above. FDOT events come from the DIVAS feed behind FL511 and mostly cover state roads; county roads and base roads usually won't appear.

      Data: NOAA MRMS (NCEP / AWS), FDOT / FL511.
